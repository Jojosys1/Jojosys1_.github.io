# Démarrage rapide

1. Créer le dépôt public `Jojosys1.github.io` sur le compte GitHub `Jojosys1`.
2. Extraire cette archive et envoyer son contenu directement à la racine du dépôt.
3. Dans GitHub, ouvrir **Settings → Pages** et sélectionner **GitHub Actions** comme source.
4. Ouvrir l’onglet **Actions** et vérifier le succès du workflow de publication.

La page d’accueil se trouve dans `_pages/about.md`, le menu dans `_data/navigation.yml`, le profil dans `_config.yml` et les projets dans `_portfolio/`.

Ne déplace pas les dossiers du thème (`_includes`, `_layouts`, `_sass`, `assets`, etc.) : ils assurent le rendu du site.
